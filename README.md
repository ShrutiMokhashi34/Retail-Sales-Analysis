# Retail Sales Analysis

An end-to-end data analytics project that transforms raw retail sales data into actionable business insights using **Python**, **SQL**, and **Tableau**. The project demonstrates the complete analytics workflow, including data cleaning, exploratory data analysis, SQL-based business analysis, and interactive dashboard development.

---

## Project Overview

This project analyzes a retail sales dataset to uncover trends in revenue, product performance, customer purchasing behavior, and regional sales.

The workflow includes:

- Data cleaning and preprocessing using Python
- Exploratory data analysis (EDA)
- Business insights using SQL
- Interactive dashboard creation in Tableau

---

## Tech Stack

- **Programming Language:** Python
- **Database Query Language:** SQL
- **Libraries:** Pandas
- **Visualization:** Tableau Public
- **Dataset:** Kaggle Retail Sales Dataset (Dataset URL: https://www.kaggle.com/datasets/ankitbansal06/retail-orders)

---

## 📂 Project Workflow

### 1. Data Cleaning (Python)

- Imported raw Excel dataset from Kaggle
- Cleaned data according to requirements
- Standardized column names
- Corrected data types
- Exported cleaned dataset for SQL analysis

**Tools Used**
- Python
- Pandas

---

### 2. Data Analysis (SQL)

Performed business analysis using SQL queries, including:

- Top 5 highest revenue-generating products by region
- Month-over-Month sales comparison (2022 vs 2023)
- Highest sales month for each product category
- Top sub-categories with highest YoY revenue growth
- Revenue aggregation and ranking using:
  - Common Table Expressions (CTEs)
  - Window Functions
  - Aggregate Functions
  - CASE Statements

---

### 3. Dashboard Development (Tableau)

Developed an interactive Tableau dashboard featuring:

- Monthly Revenue Trend (2022 vs 2023)
- Revenue by Region
- Top Revenue Generating Products
- Revenue by Category
- Total Revenue KPI
- Revenue Growth KPI
- Interactive filters for:
  - Subcategory
